# 🛒 Amazon Clone

Responsive Amazon homepage clone built using HTML and CSS to replicate modern e-commerce UI/UX design.

---

# 🚀 Features

- Responsive homepage design
- Amazon-inspired navigation bar
- Product showcase sections
- Hero banner implementation
- Modern UI styling
- Clean frontend layout

---

# 🛠️ Tech Stack

- HTML5
- CSS3

# 🎯 Project Goal

The goal of this project was to strengthen frontend development skills by recreating a modern e-commerce website inspired by Amazon.
